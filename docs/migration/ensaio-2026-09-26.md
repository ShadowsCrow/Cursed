## Repetição e rollback

Defina `CURSED_TEST_POSTGRES_URL` para uma instância PostgreSQL descartável e
execute, apontando para a base SQLite legada local:

```text
python platform/migration/ensaio_migracao.py --origem-sqlite CAMINHO_DO_CURSED_DB --origem-id ensaio-local-2026-09-26 --mesa-id mesa-ensaio
```

O script cria um backup temporário sob `platform/api/.dev/`, migra somente
esse backup e cria um banco com prefixo `cursed_ensaio_`. Ao final, encerra as
conexões, remove o banco com `DROP DATABASE ... WITH (FORCE)` e elimina o
backup temporário. Esta execução confirmou `rollback_banco_confirmado: true`
e `backup_temporario_removido: true`; um teste automatizado também consultou
`pg_database` para verificar a ausência do banco após o ensaio. O contêiner
PostgreSQL descartável pode então ser encerrado. Para o corte real, congelamento
de escrita, backup verificado e rollback em ambiente equivalente ao produtivo
continuam nas tarefas 12.9 e 12.10.
