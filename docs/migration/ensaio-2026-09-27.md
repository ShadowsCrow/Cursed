## Repetição e rollback

Com `CURSED_TEST_POSTGRES_URL` apontando para um PostgreSQL descartável:

```text
python platform/migration/ensaio_migracao.py --origem-sqlite CAMINHO_DO_CURSED_DB --origem-id ensaio-local-2026-09-27 --mesa-id mesa-ensaio
```

Resultado: `rollback_banco_confirmado: true` e `backup_temporario_removido: true`. O teste `test_ensaio_migracao`, com PostgreSQL, também passou e confirmou a remoção do banco em `pg_database`.

Para uma mesa já migrada, o complemento sozinho roda em prévia e depois com `--aplicar`:

```text
python platform/migration/completar_fichas.py --mesa-id MESA
python platform/migration/completar_fichas.py --mesa-id MESA --aplicar
```
