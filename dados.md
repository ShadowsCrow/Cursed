ROLAGEM DE PERICIA:

Dados de pericias: Atributo + pericia = quantidade de dados d10;
Dificuldade normalmente é 6

Exemplo de rolagem

destreza 3
luta 2

3 + 2 = 5d10

[5, 7, 9, 1, 9]

Seriam 3 sucessos porém o 1 faz com que sejam 2 falhas a mais ao inves de 1
Ou seja foram 3 falhas e 2 sucessos e a dificuldade do teste era 3 sucessos então foi uma falha no teste.

ROLAGEM DE ACERTO:

Dados de acerto descritos na carta: Atributo + pericia de ataque = quantidade de dados d10;

ROLAGEM DE DEFESA:

Dados de defesa atributo + pericia de defesa + armadura= quantidade de dados d10

ROLAGEM DE DANO:

Dados descritos na carta de arma, habilidade ou magia, exemplo: 3d6 ou d6s (O que significa que é 1d6 para cada ponto de proeficiencia) buscando um thresholh de por exemplo 16 para o primeiro thresholh 17 para dar 2 de dano e 25 para dar 3 de dano, sendo que se já chegou ao ponto de rodar o dano pelo menos 1 de dano é garantido.
