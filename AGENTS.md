- Regras de mesa (`rules/sistema`) não mudam sem decisão do usuário; a aplicação representa as regras, não as define. Nunca inferir valores mecânicos ausentes.
- Marque uma tarefa `[x]` só quando o comportamento estiver implementado **e verificado** por testes.
- Imagens (método oficial, decisão do usuário): toda pintura ou ícone raster que faltar (artes, faixas e medalhões de categoria, ilustrações) é gerado com autonomia pelo **Codex CLI** com `$imagegen`, tendo como referência uma arte aprovada: `timeout 590 codex exec --skip-git-repo-check -m gpt-5.6-sol -s read-only -i <referência.png> - < prompt.txt`. O prompt começa com "Use $imagegen to generate exactly ONE image, and nothing else" e pede só o caminho do arquivo gerado (em `C:\Users\rique\.codex\generated_images\`). O PNG vai para `platform/frontend/arte-original/`, e `.venv/Scripts/python.exe platform/frontend/scripts/preparar_arte.py` grava o webp em `public/arte/`. Nunca substituir pintura por SVG nem por composição em código.
- Ambientes locais (lançadores em `.claude/launch.json`): a API recarrega o código sozinha, mas as migrações só rodam quando o lançador sobe. Depois de criar uma migração, rode `alembic upgrade head` no banco de cada ambiente em uso (`CURSED_PLATFORM_DATABASE_URL=sqlite:///<caminho>`), senão o código novo roda contra o banco velho e as gravações falham em silêncio na tela (lição de 2026-10-06, ambiente da porta 5197, banco em `%LOCALAPPDATA%\Temp\cursed-sala-local`). No Windows, a recarga da API às vezes deixa o processo filho do uvicorn travado: a porta fica ouvindo, mas `/health` não responde e a interface fica sem campanhas; o conserto é encerrar só o filho travado (`taskkill /PID <filho> /F`), que o pai religa.
- Git: `git -c safe.directory=F:/Cursed ...`. Nunca versionar `secrets.toml`, arquivos `.env*` nem skills fora das `openspec-*`.
